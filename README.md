# AI Question & Answer Assistant

A simple AI chatbot built with Python and the OpenAI API.

## Features

- Ask questions and receive AI-generated answers
- Simple command-line interface
- Exit the chatbot at any time

## Technologies

- Python
- OpenAI API
- python-dotenv

## Installation

Install the required libraries:

```bash
pip install openai python-dotenv
```

Create a `.env` file and add your API key:

```text
OPENAI_API_KEY=your_api_key_here
```

**Never upload your `.env` file or API key to GitHub.**

## Run

```bash
python main.py
```

## Example

```text
You: What is artificial intelligence?

AI: Artificial intelligence is the ability of computers
to perform tasks that normally require human intelligence.

You: exit

Goodbye!
```
